#Cwitter---Grupo-Codex
-Usuarios:
- Guardamos un archivo de indices para cada usuario, se accede mediante lista si es el usuario loggeado, para permitir que pueda agregar, quitar, modificar un posteo en posicion N, si no es el usuario loggeado se carga en una lista para permitir filtrar las publicaciones segun usuario.
- Guardamos un segundo archivo que guarde los nombres de usuarios y contraseñas
- El usuario loggeado se carga en memoria
-Posteos:
- Guardamos un archivo general de los posteos, se puede acceder el  indice de cada usuario o directo, si se accede de manera directa se carga parcialmente en una lista, tambien se puede filtrar por palabras clave
